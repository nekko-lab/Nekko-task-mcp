## 📋 ネッコ研のタスク、見られるようになりました

Discord でのやりとりから「誰が・何を・いつまでに」を毎朝自動で拾って、研究会のタスク台帳にまとめています。見方は3つあります（どれか1つでOK）。

### 1. Discord で見る（設定なし）
毎朝 9:00 に **#📋｜タスク** に、その日の締切・期限切れ・新しく増えたタスクが投稿されます。
**期限切れ・今日まで・明日まで** のタスクがある人にだけメンションが飛びます（1人1回。全員宛ては @MO / @NC）。

いつでも自分の担当を見たいときは、どのチャンネルでも
- `/タスク 自分` … 自分の担当（@MO 宛ての「MO全員」タスクも含む）
- `/タスク 締切` … 近い締切
- `/タスク 一覧` … 未完了タスク（チームで絞り込み可）

と打てば、**自分にだけ見える形で** 返事が来ます（チャンネルは汚れません）。

### 2. カレンダーで見る
Google カレンダーで「**ネッコ研 タスク**」を追加すると、締切が担当者名つきで自分のカレンダーに出ます。
- 追加用リンク：（※代表がここに共有リンク or iCal アドレスを貼る）
- iPhone / Mac のカレンダーなら「照会カレンダーを追加」に iCal アドレスを貼ればOK

### 3. 自分の Claude から聞く
claude.ai の **設定 → コネクタ → カスタムコネクタを追加** で、次の URL を登録してください（認証は空欄でOK）。

```
（※代表がここにメンバー用URLを貼る）
```

登録後、Claude に話しかけるだけで使えます。
- 「ネッコ研で私（◯◯）の担当タスクは？」
- 「今週締切のネッコ研タスクを教えて」
- 「MO のタスク一覧」
- 「Growi で照明の配線図について書いてあるページを探して」
- 「Growi の最新の MO会議 の議事録を要約して」

このURLでできるのは **タスクと Growi の閲覧だけ** です（Discord のメッセージは読めません。タスクや Growi の追加・変更・削除もできません）。
Growi に書き込みたいときは、今まで通り Growi で直接編集してください。

#### 権限のおすすめ設定
コネクタを追加したら、コネクタの設定画面でツールごとの権限を **「常に許可」** にしておくと、毎回の確認なしで使えます（全部読み取り専用なので安全です）。

### 間違っていたら
自動で拾っているので、担当違い・終わったのに残っている、などがあり得ます。
気づいたら Discord で代表（フォルテライト）に一言ください。直します。
